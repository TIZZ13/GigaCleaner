Политика конфиденциальности

Дата вступления в силу: 25 ноября 2026

Эта политика описывает, как приложение GigaCleaner и его сайт обращаются с данными.

1. Приложение работает локально

GigaCleaner — настольная утилита для Windows. Очистка и оптимизация выполняются полностью на вашем компьютере. Никакие личные данные, имена файлов или информация о системе не собираются, не передаются и не продаются.

2. Что приложение открывает на компьютере

Локальный доступ к следующим областям — только при выполнении соответствующего действия:

  • Временные файлы и кэши — для очистки (только по белому списку путей);
  • Реестр и службы Windows — для удаления устаревших записей и управления автозагрузкой (перед изменениями создаётся точка восстановления);
  • winget / Центр обновления Windows — для проверки обновлений программ и драйверов (сетевые запросы только для этих проверок).

Приложение действует только по вашей команде: сканирование, очистка, оптимизация или проверка обновлений.

3. Сетевые запросы

Приложение обращается в интернет ровно в трёх случаях:

  • Проверка обновлений ваших программ через winget и Windows Update — только когда вы открываете страницу «Обновления» или нажимаете «Проверить»;
  • Проверка новой версии самого приложения — при запуске запрашивается файл https://tizz13.github.io/GigaCleaner/version.json (крошечный JSON с номером версии и ссылкой на установщик). Никаких идентификаторов, данных об устройстве и статистики использования не передаётся;
  • Скачивание нового установщика — только после того, как вы подтвердите диалог обновления.

Все остальные операции выполняются офлайн.

4. Чего приложение не делает

  • Не собирает аналитику, телеметрию или отчёты о сбоях;
  • Не отслеживает вашу активность;
  • Не читает документы, фотографии и сообщения;
  • Ничего не передаёт третьим лицам;
  • Не требует аккаунта или регистрации.

5. Данные, хранящиеся на вашем компьютере

Настройки (язык, тема, расписание, горячая клавиша, список «сохранения входа») хранятся локально в файле %AppData%\GigaCleaner\settings.json. Этот файл никогда не покидает ваш компьютер. При удалении приложение спрашивает, удалить ли настройки вместе с ним.

6. Сайт (GitHub Pages)

Сайт https://tizz13.github.io/GigaCleaner/ — статическая страница на GitHub Pages. GitHub может вести стандартные серверные журналы (IP-адрес, user agent), как для любой публичной страницы. На сайте не используются аналитика и cookie.

7. Изменения политики

Мы можем обновлять политику по мере развития приложения. Актуальная версия всегда публикуется в этом файле, а также в PRIVACY.md репозитория на GitHub.

8. Контакты

По вопросам, связанным с политикой, откройте issue в репозитории проекта.
