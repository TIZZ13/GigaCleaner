## Как записывались

1. Окно приложения выставлялось в размер 1280×1100 (8 вкладок), кадры снимались через
   PrintWindow каждые ~70 мс, затем собран GIF 1280×720 (crop сверху), 15 fps, с паузами
   на ключевых сценах (обзор / результат сканирования / финал).
2. Длительность ~24 с — в требуемом диапазоне 20–30 с, размер 0,46 МБ — в пределах 5 МБ.
3. Скриншоты: снимки вкладок 1280×1100, обрезаны до 1280×720 по верхней части кадра.
   Обзор (`screen-1.png`), очистка с результатом (`screen-2.png`, скан нашёл 404,2 МБ),
   планировщик/автозапуск (`screen-3.png`).

## Важно (проверено)

- **Без персональных данных**: в кадрах нет реальных имён пользователя, путей к
  документам, вкладок браузера с личными данными. Показаны только размеры и названия
  категорий (Временные файлы, Кэши браузеров, Корзина, Дампы и журналы и т.п.).
- Вкладки «Мониторинг» (реальные процессы) и «Инструменты» (реальный список программ)
  в публичные медиа **не включались**.
- Чужие бренды и чужие видео (в т.ч. записи сайтов конкурентов) не использовались —
  только собственные снимки GigaCleaner.

После изменения медиа обновите ссылки в `README.md` и `README.ru.md` и добавьте
файлы в репозиторий.
