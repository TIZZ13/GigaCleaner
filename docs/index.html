Вопросы
Частые вопросы
Программа удалит мои документы или фотографии?

Нет. Очистка работает по белому списку путей: Program Files, AppData\Roaming, «Документы» и System32 не затрагиваются. Временные файлы %TEMP% удаляются только старше 24 часов.

Нужны ли права администратора?

Да, приложение запрашивает права администратора — это нужно для очистки системных папок и работы с реестром и службами.

Что происходит при обновлении или удалении?

Установщик вежливо закрывает работающее приложение, обновляет файлы и снова запускает его. Настройки хранятся отдельно в %AppData%; при удалении программа спрашивает, удалить ли их вместе с приложением.

Программа что-то отправляет в интернет?

Нет. GigaCleaner работает локально и без телеметрии. Единственный сетевой запрос — проверка новой версии (по выбору приложения, раз в запуск).
